## 📌 Module Overview

### `auth.py`
Handles authentication operations such as lagin, signup, password verification, and session handling.

### `database.py`
Responsible for database connection, queries, table creation, and data storage.

### `users.py`
Managers user-related operations and account handling.

### `validations.py`
Contains input validation logic including email validation, password validation, and data checking.

### `utils.py`
Includes reusable helper functions used throughout the project.

### `main.py`
Acts as the main enrty point of the application.

## 🧪 Example Workflow

1.User creates an account
2. System validates user input
3. Password gets securely hashed
4. User data is stored in the database
5. User logs in securely using authentication verification
